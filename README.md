# Imaginaque
ImaginaQue es un proyecto de creación automatizada de contenido audiovisual mediante inteligencia artificial. Genera historias originales, guiones atractivos, escenas 3D, voces y vídeos cinematográficos para TikTok y YouTube Shorts, automatizando todo el proceso desde la idea inicial hasta la edición y publicación.

## Vídeo con Remotion

Este repositorio incluye un proyecto [Remotion](https://www.remotion.dev) (v4) y las skills oficiales de Remotion para agentes en `.agents/skills` (enlazadas desde `.claude/skills`).

```bash
npm install        # instalar dependencias
npm run dev        # abrir Remotion Studio
npx remotion render  # renderizar un vídeo en ./out
```
